## Overview

Connect your SEC Filings Scraper app to Google Sheets to automatically export fetched filing data. The integration handles header initialization on first write, appends subsequent results without overwriting, and supports worksheet auto-creation. Use this for ongoing tracking of filings by keywords, companies, or form types.

<Callout kind="info">
  Enable the Google Sheets API in your Google Cloud project and create a service account for authentication.
</Callout>

## Prerequisites

Before starting, prepare these items:

- A Google Cloud project with the Sheets API enabled
- A service account JSON key file (download from Google Cloud Console)
- A Google Sheet shared with the service account's `client_email` (found in the JSON)
- Python dependencies: `gspread`, `google-auth`, `pandas`

## Worksheet Management

The app supports existing and new worksheets seamlessly.

<Tabs>
  <Tab title="Existing Worksheet" icon="file">
    Select from the dropdown after testing the connection. Data appends to the next empty row.
  </Tab>
  <Tab title="Auto-Creation" icon="plus">
    If the specified `worksheet_title` does not exist, the app creates it automatically before writing.
  </Tab>
</Tabs>

<CodeGroup tabs="Python">
  ```python
  # Example: write_df_to_sheet function logic
  import gspread
  import pandas as pd

  def write_df_to_sheet(gc, spreadsheet_id, worksheet_title, df):
      sh = gc.open_by_key(spreadsheet_id)
      try:
          wks = sh.worksheet(worksheet_title)
      except gspread.WorksheetNotFound:
          wks = sh.add_worksheet(title=worksheet_title, rows="1000", cols="20")
      
      # Header check and write
      headers = wks.row_values(1)
      if not headers:
          wks.update(f'A1:{chr(64 + len(df.columns))}1', [df.columns.tolist()])
          start_row = 2
      else:
          start_row = len(wks.get_all_values()) + 1
      
      if not df.empty:
          wks.append_rows(df.values.tolist(), value_input_option='RAW')
  ```
</CodeGroup>

## Header-First Writes and Data Appending

On the first export to an empty worksheet:

- Headers write to row 1 (e.g., `Date`, `Form`, `URL`, `Symbol`, `CIK`)
- Data starts at row 2

Subsequent exports append data rows only, preserving headers and prior data. This prevents duplication and column misalignment.

<Callout kind="tip">
  Empty fetches (zero results) trigger header-only writes if the sheet is new, ensuring structure without data.
</Callout>

## Troubleshooting

<ExpandableGroup>
  <Expandable title="Connection Failed" default-open="true">
    - Verify the sheet is shared with the service account `client_email`
    - Check the spreadsheet ID from the URL: `https://docs.google.com/spreadsheets/d/{ID}/edit`
    - Ensure the JSON file is valid and not expired
  </Expandable>
  <Expandable title="Write Errors">
    - Confirm Sheets API is enabled in Google Cloud
    - Test permissions by manually appending a row via the Google Sheets UI with the service account
    - Review console logs for `gspread` exceptions
  </Expandable>
  <Expandable title="Headers Missing">
    Manually clear row 1 and re-fetch to trigger header initialization. Headers write only on first empty-sheet write.
  </Expandable>
  <Expandable title="Column Drift">
    Fixed in v2.0: Uses explicit A1 ranges like `A1:P1` for headers and appends prevent shifts.
  </Expandable>
</ExpandableGroup>
