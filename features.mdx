## Overview

SEC Filings Scraper provides powerful tools to retrieve and manage SEC filings efficiently. You can apply advanced filters for precise searches, use predefined groups for common filing types, and handle large datasets with built-in pagination and retry logic. Results appear in an interactive table, with options to download as CSV or export directly to Google Sheets.

<Callout kind="info">
  Connect your Google Sheets account first via the sidebar to enable automatic exports.
</Callout>

## Pagination and Retry Logic

The app fetches up to 100 results per page automatically, continuing until all hits are retrieved. Built-in retry handles SEC rate limits and transient errors.

<Steps>
  <Step title="Fetch Process" icon="download">
    Enter parameters and click "🔎 Fetch Filings". The app paginates seamlessly.
  </Step>
  <Step title="Retry Handling" icon="refresh-cw">
    On errors like 429 (rate limit), it applies exponential backoff: `(2^attempt - 1) * 0.5s + jitter`, up to 6 attempts.
  </Step>
  <Step title="Complete Results" icon="check-circle">
    All pages combine into one table; status shows total records fetched.
  </Step>
</Steps>

Here's a code example of the API call structure:

<CodeGroup tabs="Python">
  ```python
  import requests

  url = "https://efts.sec.gov/LATEST/search-index"
  params = {
      "q": "acquisition",
      "entityName": "AAPL",
      "forms": "8-K,10-Q",
      "dateRange": "custom",
      "startdt": "2024-01-01",
      "enddt": "2024-12-31",
      "from": 0,
      "size": 100
  }
  response = requests.get(url, params=params)
  filings = response.json().get("hits", {}).get("hits", [])
  ```
</CodeGroup>

<Expandable title="Advanced Retry Configuration" default-open="false">
  Customize `max_total_retries` in code for stricter control. Session uses `urllib3.Retry(total=3, backoff_factor=0.5)` for HTTP errors.
</Expandable>

## Reviewing and Exporting Results

Results display in a sortable table with columns like Form, Filed, URL, Symbol, and CIK. Click URLs for direct SEC access.

### Export Workflow

1. Review the table for accuracy.
2. Download as CSV via the button.
3. Results auto-append to your selected Google Sheet (headers added only on first write).

| Action          | Behavior                          |
|-----------------|-----------------------------------|
| CSV Download    | Saves full dataset locally        |
| Sheet Append    | Adds rows starting at next empty; skips if no data |

This ensures you capture complete, reliable filing data for analysis.
